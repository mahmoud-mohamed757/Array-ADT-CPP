# Array ADT in C++

A simple implementation of the Array Abstract Data Type (ADT) using C++ and dynamic memory allocation.

## Features

- Fill the array with user input
- Display array elements
- Get the array capacity and current length
- Search for an element using linear search
- Append an element
- Insert an element at a specified index
- Delete an element by index
- Enlarge the array capacity
- Merge two arrays

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and encapsulation
- Dynamic memory allocation using `new` and `delete[]`
- Pointers and arrays
- Linear search
- Array insertion and deletion
- Memory management

## How to Run

Compile the program using a C++ compiler:
```
g++ main.cpp -o ArrayADT
```

Run on Windows:
```
ArrayADT.exe
```
